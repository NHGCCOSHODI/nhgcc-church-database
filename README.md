# NHGCC Oshodi Church Management System (Desktop Edition)

Official multi-device Windows desktop management application for **National Holy Ghost Church of Christ (NHGCC), Oshodi Parish, Lagos**.

---

## 🌟 Key Features

- **Central Cloud Synchronized**: Backed by a live **Supabase PostgreSQL** cloud database. Any attendance marked or member added on any PC is instantly visible across all church worker computers in real time.
- **Native Windows Desktop Experience**: 1-click self-installation with automatic desktop shortcut and Start Menu launcher. No command line or technical knowledge required.
- **Attendance & Fast Check-In**: Quick member search by name or code (`NHGCC-XXXX`), real-time attendance tracking, first-timer detection, and export to Excel.
- **Comprehensive Membership Directory**: Complete registry of all 298 parish members, department filters, birthdays, and pastoral follow-up tracking.
- **Pastoral Care & Follow-Up**: Track members missing multiple consecutive services, log visitation and call outcomes.
- **Reporting & Notifications**: Automated email notifications and service attendance summaries.

---

## 📥 Installation for Church Workers

1. Go to the [Releases](https://github.com/NHGCCOSHODI/nhgcc-church-database/releases) section.
2. Download the latest `NHGCC_Church_Database.exe`.
3. Double-click `NHGCC_Church_Database.exe` to run it.
4. Click **"Install NHGCC App"** in the setup window:
   - It automatically registers the app.
   - It places an official **NHGCC Church Database** icon on your **Desktop** and **Start Menu**.
5. The application launches automatically in your browser window and connects directly to the shared church database!

---

## 🛠️ Technology Stack

- **Desktop Shell**: Python 3.13 / PyInstaller / Tkinter native launcher
- **Backend**: Flask 3.1, Flask-SQLAlchemy 3.1, Psycopg 3
- **Cloud Database**: PostgreSQL 17 on Supabase Cloud
- **Frontend**: Tailwind CSS, Feather Icons, Chart.js
